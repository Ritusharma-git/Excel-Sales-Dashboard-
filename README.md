Excel Sales Dashboard 📊

🔍 Project Overview

This project is an Excel-based dashboard where raw sales data is cleaned and transformed into meaningful insights.

🧹 Data Cleaning

- Removed duplicate values
- Handled missing data
- Used formulas like TRIM, IF, VLOOKUP

📊 Dashboard Features

- Pivot Tables for data analysis
- Charts (Bar, Pie, Line)

🛠 Tools Used

- Microsoft Excel
